# 大肥鱼爬塔 · 战斗原型

仿《杀戮尖塔》的像素爬塔 roguelike。这是第一个可玩的版本：海边连打三场，每场赢了选一张牌，第三场精英战前再挑一件遗物。

这个游戏和桌宠是分开的：不共用代码、存档和货币，整个目录可以直接搬成独立仓库。

## 运行

```bash
npm install
npm run dev        # 本地开发，浏览器打开 http://localhost:5173
npm test           # 战斗规则测试
npm run build      # 打包成单个 dist/index.html，双击就能玩，不需要服务器
```

地址后面加 `?seed=123` 可以跳过标题、复现同一局。

## 怎么玩

- 每回合 3 点算力，抽 5 张牌；敌人头顶显示它下回合要做什么。
- 把牌拖到敌人身上，或者先点牌、再点敌人；只剩一个敌人时点牌直接打出。
- 数字键 1–0 选牌，E 结束回合，右键或 Esc 取消选择。必杀特写可以点一下跳过。
- 右上角可以切 2 倍速、开关音效、查看牌组。

## 两个流派

| 流派 | 玩法 | 代表牌 |
| --- | --- | --- |
| 鲸尾 | 物理连击，本回合打出的攻击牌越多越疼 | 尾巴连拍、干饭冲刺、鲸尾回旋、鲸落、吃饱了才有力气 |
| 深度思考 | 抽牌、过牌，本回合消耗的牌越多越疼 | 已思考3秒、内心OS、不语只是一味地OS、上错模型了、超长思维链、思考完毕 |

大肥鱼头顶会显示「连击 ×N」和「已思考 N 秒」，对应两个流派的计数。

## 梗

道具和卡名取自大肥鱼 / DeepSeek 社区的梗：吃白饭、吃饭的铁盆、已思考3秒、上错模型了、服务器繁忙、得加钱、DeepSleep、不语只是一味地OS、「你骂我也没用，因为我是吃白饭的蓝色大肥鱼」。

| 遗物 | 效果 |
| --- | --- |
| 剩饭（初始） | 每场战斗结束恢复 6 点生命 |
| 电饭煲 | 第 3、6、9…回合开始时饭煮好了，获得 2 点算力 |
| 吃饭的铁盆 | 每场战斗开始获得 10 点格挡 |
| 呆毛 | 每回合第一次消耗牌时抽 1 张 |

敌人：训练木桩、钳钳蟹、抢饭海鸥（叼着饭团），精英「服务器繁忙水母」会往你的弃牌堆里塞「服务器繁忙」，头上一直转着加载圈。

## 结构

| 路径 | 说明 |
| --- | --- |
| `src/core/` | 纯规则，不碰页面：带种子的随机数、战斗（`combat.ts`）、一局流程（`run.ts`） |
| `src/content/` | 卡牌、遗物、敌人和遭遇，都是数据 |
| `src/render/` | 384×216 像素画布：场景、敌人画法、图标、巨鲸必杀特写 |
| `src/ui/` | 手牌、血条、意图、奖励界面，以及把规则事件逐拍播成动画的播放器 |
| `tools/import-sprites.mjs` | 把生成的姿势表处理成游戏用的小精灵图 |
| `tests/` | 规则测试（vitest） |

规则层出牌后立刻算完，返回一串事件（「对 e0 造成 6 点伤害」「消耗一张牌」……），表现层再按顺序配上动画播放。动画快慢不影响结果，同一个种子总是打出同一局。

## 美术

- 角色姿势来自 `demos/whale-tail/assets` 的鲸尾和必杀技姿势表，用下面的命令重新处理成 72 像素高的战斗精灵和 100 像素高的特写精灵，全部压到同一套 40 色调色板：

  ```bash
  node tools/import-sprites.mjs ../demos/whale-tail/assets
  ```

- 必杀「巨鲸破浪」直接移植自 `demos/whale-tail/deep-sea.js`，像火纹 GBA 那样切到单独的战斗镜头，伤害数字按实际结算显示。
- 怪物、遗物图标和意图图标都是代码画的，带 1 像素深色描边。
- 背景暂时沿用演武场的海边夕照。按《彩虹岛》那样做饱和度更高的多层背景，留到下一步的美术阶段。
