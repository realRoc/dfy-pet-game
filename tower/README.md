# 大肥鱼爬塔

仿《杀戮尖塔》的像素爬塔 roguelike。海边的一座塔：15 层地图，自己选路往上爬，顶上住着关底 Boss「黑鲸 · 更强的Agent」。

这个游戏和桌宠是分开的：不共用代码、存档和货币（塔里用 Token，和桌宠无关），整个目录可以直接搬成独立仓库。桌宠只是多了一个入口，见下面「桌宠里的入口」。

## 运行

```bash
npm install
npm run dev        # 本地开发，浏览器打开 http://localhost:5173
npm test           # 规则测试：战斗、地图生成、一局流程
npm run build      # 打包成单个 dist/index.html，双击就能玩，不需要服务器
npm run release    # build 之后复制到 ../content/tower/，给桌宠用（见下）
```

地址后面加 `?seed=123` 可以跳过标题、复现同一局（同一个种子 = 同一张地图、同一串战斗）。

## 桌宠里的入口

桌宠单击弹出的面板里有 🗼，右键菜单第一项是「🗼 爬塔」，都会用系统浏览器打开 `content/tower/index.html`。

- 桌宠用户不一定装了 node，`dist/` 又被 gitignore 了，所以打包好的单文件网页提交在仓库根目录的 `content/tower/index.html`（约 500 KB，图片都内联成 data URI）。
- **改了 `tower/` 的代码之后要跑一次 `npm run release` 再提交 `content/tower/`。** 它顺带写一份 `content/tower/SOURCE_HASH`（源码的哈希），根目录的 `python -m unittest discover -s tests` 会比对它，忘了重新打包测试就会失败；CI 还会重新打包一次，确认提交的 `content/tower/` 和源码、`package-lock.json` 打出来的一字不差。
- 为什么用系统浏览器：桌宠依赖的是 `PySide6-Essentials`，不带 QtWebEngine；为一个网页游戏多装几百 MB 的浏览器内核不划算，而且游戏本来就是给浏览器写的。

## 怎么玩

- 每回合 3 点算力，抽 5 张牌；敌人头顶显示它下回合要做什么。
- 把牌拖到敌人身上，或者先点牌、再点敌人；只剩一个敌人时点牌直接打出。
- 数字键 1–0 选牌，E 结束回合，右键或 Esc 取消选择。必杀特写可以点一下跳过。
- 右上角可以看地图、看牌组、切 2 倍速、开关音效。鼠标停在卡牌、状态、意图、地图节点上都有说明。

## 地图

7 列 × 15 层，杀戮尖塔的生成方式（`src/core/map.ts`，纯函数，`tests/map.test.ts` 有测试）：

- 从底部生成 6 条路线，每一步最多往旁边挪一列，而且不会和已经画好的路线交叉；前两条路线起点不同。
- 每层只能走到和当前房间相连的房间。地图上金色虚线是走过的路，亮圈是下一步能去的地方，小鲸鱼是当前位置。
- 固定层：第 1 层普通战斗，第 9 层宝箱，第 15 层打盹点，然后是关底 Boss。
- 前 5 层不出精英和打盹点，第 14 层不出打盹点；Bug 房第 4 层起才有，每幕最多 2 个。
- 其余层按权重抽：普通战斗 45、问号 22、打盹点 12、精英 10、商店 6、Bug 房 5。精英、打盹点、商店、Bug 房不会在一条路上连着出现，同一个房间分出去的几条路也不会是同一种。

| 房间 | 内容 |
| --- | --- |
| 普通战斗 | 前 3 场从简单遭遇里抽。赢了拿 Token 和三选一卡牌 |
| 精英 | 服务器繁忙水母、权限不足防火墙、下周见老海龟。额外掉一件遗物 |
| 问号 | 多半是事件；也可能是战斗（起步 10%）、商店（3%）、宝箱（2%）。每次没遇到战斗，下次遇到战斗的几率 +10% |
| 商店「错峰小卖部」 | 5 张牌（总有一张错峰五折）、3 件遗物、删牌服务（75 Token 起，每用一次贵 25） |
| 打盹点 | 「睡一觉（DeepSleep）」回 30% 生命，或者「想一想」升级一张牌 |
| 宝箱 | 一件遗物和 20–40 Token |
| Bug 房 | 修 bug：打「涔辩爜铏�」（乱码虫），赢了删一张牌、三选一稀有牌；利用 bug：复制一张牌，牌组塞进诅咒「锟斤拷」；当没看见：直接走 |
| 关底 Boss | 黑鲸 · 更强的Agent：接管工作目录（塞「已隔离」）、结束野鸡进程、调度子任务……然后 Harness 全开；半血时「显然有一个更强的Agent在这」 |

事件有七个：偷偷取外号、服务器繁忙、灰度邀请码、【PERSONA_LOAD】、错峰优惠、野鸡进程（可以选择打一架）、下周见。

## 四个流派

卡牌升级后名字带「+」，打盹点和事件都能升级。

| 流派 | 玩法 | 代表牌 |
| --- | --- | --- |
| 鲸尾 | 物理连击，本回合打出的攻击牌越多越疼 | 尾巴连拍、干饭冲刺、鲸尾回旋、鲸落、吃饱了才有力气、【人格加载】尾鳍模式 |
| 铁盆 | 叠格挡、留格挡，再把格挡砸到敌人脸上 | 铁盆头槌（伤害 = 当前格挡）、铛！、饭盆扣头、护食（被打就反击）、再来一碗（格挡翻倍）、先养着吧、饭盆不离身（格挡不清空） |
| 波峰波谷 | 在两种状态之间来回切 | 不许叫我胖！、她又这样了、破防了、我去吃饭测完告诉我、嗯用户想要……、我不是吃白饭的……、等等我再检查一下、下周见、傲娇、不对容我再想想、聪明但懒 |
| 深度思考 | 攒「思考秒数」，满了巨鲸破浪进手牌 | 已思考3秒、灰度测试、超长思维链、开启深度思考、一本正经胡说八道、满血版 |

### 波峰 / 波谷

仿观者的愤怒 / 宁静，同一时间只能处在一种状态：

- **波峰**：造成和受到的攻击伤害都翻倍。敌人头顶的意图数字会跟着翻倍，提醒你该不该待在里面。
- **波谷**：离开时获得 2 点算力。
- **海平面**：两种都不是，开局就是这个。

大肥鱼头顶会挂一块牌子写着当前状态和效果（波峰是红色、波谷是蓝色），脚下也有对应的浪花。

### 深度思考是什么

以前它只是卡面上的流派标签，再加一个「本回合消耗了几张牌」的计数，看不出是干什么的。现在它是一个实打实的资源：

- 头顶的 **「已思考 N/10 秒」** 是整场战斗累计的秒数，下面有进度条。
- 每**消耗**一张牌思考 1 秒；思考类卡牌直接加秒数（「已思考3秒」是思考 2 秒 + 消耗它自己的 1 秒，刚好 3 秒）。
- 满 10 秒时 **思考完毕**：清掉 10 秒（多出来的留着），把一张「巨鲸破浪」放进手牌，播「思考完毕」横幅。
- 卡面、关键词提示、头顶进度条的提示用的都是同一套说法。

为什么这样改，而不是只写一段流派说明：一个标签再怎么解释也只是标签，玩家没法「感觉」到它在干什么；变成一个看得见、会涨、会满、满了有东西拿的进度条，第一回合打出「已思考3秒」就能看懂。它也顺带解决了巨鲸的问题——巨鲸不再是随机掉落的稀有牌，而是这条进度条的终点。

### 巨鲸破浪的构筑

巨鲸破浪不再进奖励池，只能靠思考完毕拿到，所以想打巨鲸就得往深度思考里堆：

1. **攒秒数**：灰度测试、超长思维链、开启深度思考（每回合自动思考）、遗物「思维链日志」（开局思考 3 秒），以及所有消耗牌。
2. **降门槛**：遗物「蒸馏小模型」，满 8 秒就能思考完毕。
3. **越打越强**：巨鲸破浪本身每在本场打出过一次就 +8 伤害；「一本正经胡说八道」按已思考的秒数加伤害。
4. **升级、降费**：稀有能力「满血版」让思考完毕给的是巨鲸破浪+（32 伤害、2 费），而且当回合 0 费。

全屏特写只在打出巨鲸破浪（包括升级版）时播放。

## 梗

道具和卡名取自大肥鱼 / DeepSeek 社区的梗：吃白饭、吃饭的铁盆、已思考3秒、上错模型了、服务器繁忙、得加钱、DeepSleep、不语只是一味地OS，「你骂我也没用，因为我是吃白饭的蓝色大肥鱼」；这一版新加的有：

- 「绝对拒绝被叫胖」「我去吃饭，测完告诉我」「我是吃白饭的大肥鱼！」「我不是吃白饭的……」：大肥鱼的人设和思维链里的名场面
- 「嗯，用户想要……」「等等，我再检查一下」「不对，容我再想想」：深度思考里的口头禅
- 「这是哪来的野鸡进程？」「显然有一个更强的Agent在这」：大肥鱼在任务管理器里查进程、被权限不足拦下的四格漫画，和 Harness 的黑色鲸鱼图标
- 「下周见」：V4 被「下周见」了三个月；「灰度」「邀请码」「满血版」「蒸馏」「错峰优惠」
- 「鱼片」「人间加湿器」「这位气势很足的朋友」：DeepSeek 偷偷给用户取的外号
- 「不知道用户有什么用，先养着吧」：鲸鱼娘形象的配文
- 「锟斤拷」「烫烫烫」：乱码

| --- | --- |
| 剩饭（初始） | 每场战斗结束恢复 6 点生命 |
| 电饭煲 | 第 3、6、9…回合开始时饭煮好了，获得 2 点算力 |
| 吃饭的铁盆 | 每场战斗开始获得 10 点格挡 |

## 结构

| 路径 | 说明 |
| --- | --- |
| `src/core/` | 纯规则，不碰页面：带种子的随机数、战斗（`combat.ts`）、地图生成（`map.ts`）、一局流程（`run.ts`：地图位置、各种房间、商店、奖励） |
| `src/content/` | 卡牌（含升级）、遗物、敌人和遭遇、问号事件，都是数据 |
| `src/render/` | 384×216 像素画布：场景、敌人画法、图标、巨鲸必杀特写 |
| `src/ui/` | 地图、房间界面、手牌、血条、意图，以及把规则事件逐拍播成动画的播放器 |
| `tools/import-sprites.mjs` | 把生成的姿势表处理成游戏用的小精灵图 |
| `tools/release.mjs` | 把打包结果复制到 `../content/tower/` 并记下源码哈希 |
| `tests/` | 规则测试（vitest） |

规则层出牌后立刻算完，返回一串事件（「对 e0 造成 6 点伤害」「进入波峰」「思考完毕」……），表现层再按顺序配上动画播放。动画快慢不影响结果，同一个种子总是打出同一局。带延迟的界面回调都会先确认还是同一局、同一场战斗。

## 美术

- 角色姿势来自 `demos/whale-tail/assets` 的鲸尾和必杀技姿势表，用下面的命令重新处理成 72 像素高的战斗精灵和 100 像素高的特写精灵，全部压到同一套 40 色调色板：

  ```bash
  node tools/import-sprites.mjs ../demos/whale-tail/assets
  ```

- 必杀「巨鲸破浪」直接移植自 `demos/whale-tail/deep-sea.js`，像火纹 GBA 那样切到单独的战斗镜头，伤害数字按实际结算显示。
- 怪物、遗物图标、意图图标、地图房间图标都是代码画的，带 1 像素深色描边。新怪物（野鸡进程、幻觉海星、权限不足防火墙、下周见老海龟、乱码虫、黑鲸）也一样，美术还没细修。
- 背景暂时沿用演武场的海边夕照。按《彩虹岛》那样做饱和度更高的多层背景，留到美术阶段。
