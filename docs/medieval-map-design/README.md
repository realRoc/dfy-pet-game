## 2. 借鉴的动森风格

目标是尽量贴近《集合啦！动物森友会》的画面观感。素材全部是原创生成的，不使用任天堂的角色、UI、音乐、名称，也不照搬具体道具。生成时把用户提供的动森截图当作风格参考图附上（只做风格参考，不进仓库）。

**造型和材质**
- 哑光的软陶 / 毛毡质感，几乎没有细碎纹理；造型圆润厚实，边缘有柔和倒角，门窗大、屋顶厚。
- 树叶是一团团圆形叶块（雪松像一层层毛毡），草地是带小三角和三叶草纹样的短草。
- 颜色柔和偏粉，黄昏暖光、柔和的环境光遮蔽和接触阴影。女巫森林是夜景：蓝紫色调、发光的池塘和蜡烛。

**镜头**
- 动森本身是 3D 游戏，镜头从斜上方约 45° 往下看。这里不做 3D，而是用“2.5D 倾斜镜头”模拟：
  - 地面按 `tilt`（0.72）纵向压扁，看起来像斜着看过去；
  - 建筑、树、角色、格子都是按同样角度生成的立体贴图，直立地画在脚底的投影位置；
  - 所有立体物件和角色按脚底前后排序，前排的树会挡住后面的东西，走进森林时就是从树林里穿过去的样子；挡住角色的物件自动变半透明。
- 为什么不做真 3D：每个建筑都要有 3D 模型，AI 生图做不出模型；还要换渲染引擎、多装依赖、重写绘制。倾斜镜头能拿到大部分观感，而且沿用现有的贴图流程。以后真要上 3D，地图配置（路线、地点、事件）都能保留。

**岛建思路（分区主题）**
- 每个区域用一两种标志物就能认出来：主城 = 红砖城墙 + 钟楼，田野 = 风泵 + 麦田，薰衣草田 = 风信子花行 + 石头筒仓，遗迹 = 断墙 + 断柱，女巫森林 = 雪松 + 坩埚 + 发光池塘，港口 = 帆船 + 灯塔，湖心岛 = 凉亭 + 垂柳。
- 麦子、花行、灌木都是立体贴图一丛丛摆，不铺平面纹理，这样斜着看才有动森那种高低层次。
- 原创的圆身陶土小人代替游戏里的陶俑，排在陶俑小路两边。

## 3. 地图

按俯瞰图的布局还原，世界 3800×2800，窗口一次看大约四分之一，镜头跟着大肥鱼。起点在主城广场（居民服务处前）。
机场是动森的系统设施，不做；彩虹沙滩、社区、螺旋花园保留成沿路风景。

| 区域 | 位置 | 标志物 |
| --- | --- | --- |
| 主城 | 正中台地，四周环河 | 城门、城墙塔楼、钟楼大厅、酒馆、集市、喷泉、花环拱门 |
| 港口 | 西北海边 | 码头帆船、灯塔、木箱 |
| 薰衣草田 | 港口南边 | 薰衣草花行、石风车、画架 |
| 古城遗迹 | 正北 | 残墙、断柱、石像 |
| 螺旋花园 | 遗迹南边 | 螺旋树篱 |
| 湖心岛 | 东北紫霓湖中 | 凉亭、垂柳，两座桥连岸 |
| 陶俑小路 | 湖与东河之间 | 两排陶俑 |
| 女巫森林 | 东边 | 深色松林、女巫小屋、坩埚、发光蘑菇、石井 |
| 彩虹沙滩 | 东南 | 彩色遮阳伞 |
| 田野 / 社区 | 西南 / 西边 | 风车、农舍、稻草人、麦田 / 小屋 |

路线（三个岔路口）：

```
主城广场(起点) → 北门桥 → 北岔路 ─┬─ 薰衣草田 → 港口岔路 ─┬─ 沿北岸：古城遗迹 ────────┐
                                 │                       └─ 往南：社区 → 田野 → 西南河口 ──────────────┐
                                 └─ 螺旋花园（近路）──────────────────────┴→ 湖边岔路 ─┬─ 过桥上湖心岛 ─┐  │
                                                                                      └─ 陶俑小路 ────┴→ 女巫森林 → 彩虹沙滩 → 南沙滩 ─┤
                                                                                                         西南河口汇合 → 回城 → 主城广场
```

- 港口岔路就是“左上角往下的那条路”：从港口往南穿过社区和田野，到西南河口和南沙滩汇合，一起回城。
- 北岔路：薰衣草田 + 港口一线能去遗迹或社区；螺旋花园近路直达湖边。
- 湖边：上湖心岛要绕湖，多几步，岛上有湖心亭事件和宝箱；陶俑小路短，陶俑会把你往前推。

## 4. 格子与特殊地点事件

格子要和地点合得上：城里没有钓鱼，钓鱼点只放在港口码头、湖心岛的桥、海滩和河口；
还没想好放什么的格子一律是**空白格**（平的石板，没有事件），以后再逐个填。

每个区域有一种专属格子，落地时从下面随机抽一个事件。事件只用几种积木组合，方便以后继续加梗：
`coins`（加减小鱼干）、`say`（台词）、`expression`（指定表情或随机）、`move`（强制前进 / 后退几格，不触发终点事件、不发起点工资）、
`warp`（传送到这张地图里某种格子，不发起点工资）、`skip_next`（下回合歇着）。

| 格子 | 事件 |
| --- | --- |
| 主城 | 帮集市商人吆喝 +2；吟游诗人唱歌（开心）；面包房没忍住买了可颂 -1 |
| 陶俑小路 | 陶俑们一起摇摆，大肥鱼跟着跳（随机表情）；挖出小陶俑卖给博物馆 +1；陶俑咕噜咕噜把你推前 1 格 |
| 古城遗迹 | 断墙下挖到古钱币 +3；踩到机关被石球追着退 2 格；石像好像动了一下（震惊） |
| 女巫森林 | 女巫借你扫帚飞 3 格；喝了魔药变成青蛙，花 2 小鱼干才变回来；坩埚咕嘟咕嘟什么也没发生（疑惑） |
| 港口 | 帮渔夫卸货 +2；船长说顺路，坐运河小船直接去湖心岛；远处的海盗旗（震惊） |
| 湖心岛 | 在湖心亭钓到金鱼 +3；在凉亭看日落（比心）；往许愿池扔了 1 小鱼干 |
| 田野 | 帮农夫收麦子 +2；风车下捡到一袋面粉 +1；稻草人：别踩我的麦子！（震惊） |
| 薰衣草田 | 躺在花里睡着了，下回合歇着；画家把你画进画里 +2；薰衣草好香（比心） |

## 5. 美术生产

- 用 Codex 内置 image_gen 生成（清单 `tools/art_prompts/medieval.tsv`，脚本 `tools/gen_art.sh`），第一张城门作为风格锚点，后面每张都附上它保证统一。
- 提示词描述风格而不写游戏名：圆润玩具感、柔和高光、暖色黄昏光、3/4 俯视、移轴微缩感、透明背景、无文字。
- 地面纹理：三叶草草地、暖色石板路、土路、青绿水面、沙滩、分层崖壁、麦田行、薰衣草行。麦田和薰衣草田用整块纹理铺，不用一棵棵摆。
- 石板格子：一张 4×4 图集，每个区域一个图案（城堡、麦穗、薰衣草、断柱、陶俑、女巫帽、船锚、凉亭……）。
