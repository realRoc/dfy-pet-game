# 让她去 QQ / Discord 里聊天

桌宠右键「🔗 连接 IM」（或单击面板的 🔗）：填上你自己建的机器人的密钥，她就会用自己的身份在 QQ / Discord 里回大家的话，
聊到开心时桌面上的她也会冒个泡、做个表情。用的是你在「设置 Key」里填的 DeepSeek Key。

QQ 有两条路，选一条就行：

| | 不装 dsh，桌宠直连（本页） | 装 dsh + dsh-qqbot（[README](../README.md#装进-deepseek-harnessdsh-插件)） |
| --- | --- | --- |
| 怎么接 | 在 QQ 开放平台建机器人，把 AppID / AppSecret 填进桌宠 | 手机 QQ 扫码绑定 |
| 谁在回话 | 桌宠自己调 DeepSeek | dsh 的 `dfy-qq` preset |
| 适合 | 只想要桌宠 | 已经在用 dsh |

两条路用的是同一份人设（`cordis.patch.yml` 里 `dfy-qq` 的那段），守的是同一套规矩。

## 她在 IM 里能做什么、不能做什么

- **只能聊天**，外加让主人桌面上的自己冒一句话、做个表情、跳一段（20 秒最多一次，台词截到 60 字）。
  没有 shell、文件、网络这类工具，IM 里的人碰不到你的电脑。
- 回复里不会真的 @ 任何人（文字里写了 @everyone 也只是文字）。
- **回复上限**（设置窗底下能改）：默认每人每分钟 4 条、所有人每分钟 20 条、每天 300 条。超了只提示一次，之后不理，不花 API 费用。
- **白名单**（可选）：都空着就谁都能找她。填了任何一项，就只回名单里的群 / 服务器、频道、人；
  这时私聊只回「只回这些人」里的人。白名单外的消息她直接不理，也不提示。
- 密钥只存在本机的 `config.json` 里，不打到日志、不显示在状态里。

## Discord

1. 打开 [Discord 开发者后台](https://discord.com/developers/applications) → **New Application**，起个名字。
2. 左边 **Bot** → **Reset Token**，复制 token。下面的 Privileged Gateway Intents **都不用开**：
   她只看 @了她的消息和私信，这两种 Discord 本来就会发给机器人。
3. 桌宠「🔗 连接 IM」→ Discord：粘贴 token，点「测试连接」。成功后「邀请进服务器」会出现一个链接，
   权限只有三个：看得见频道、发消息、读消息历史（回复某条消息要它）。用它把机器人拉进你的服务器。
4. 点「连接」。状态变成 🟢 在线以后，在频道里 @她，或者直接私信她。

国内网络连 Discord 需要代理；桌宠走系统的网络设置。

## QQ（直连开放平台）

1. 在 [QQ 开放平台](https://q.qq.com/) 注册并创建一个机器人，在「开发设置」里拿到 **AppID** 和 **AppSecret**。
2. 「开发设置」里把你这台电脑的**公网出口 IP** 加进 IP 白名单（不加的话能连上，但回消息会被拒）。家里宽带的 IP 会变，变了要回来改。
3. 机器人提审上线之前只能在**沙箱**里用：在「沙箱配置」里加上你的测试群和测试成员，只有他们找她才收得到。
4. 桌宠「🔗 连接 IM」→ QQ：填 AppID、AppSecret，「测试连接」，再「连接」。
5. 单聊直接发消息，群里要 @她 才回。

QQ 的规矩：机器人只能**被动回复**（别人发来消息后的一段时间内回），不能主动找人聊；群里只收 @她 的消息。
桌宠走的是开放平台的 WebSocket 网关，是机器人主动连出去的，不需要公网回调地址。

## 想自己接别的平台

`im/` 的结构（详见 `im/__init__.py`）：平台适配器（`im/base.py` 的 `Adapter`）只负责把平台事件变成 `Incoming`、
把回复发回去；白名单、限流、人设、桌面动作的校验和冷却都在 `im/core.py` 的 `Hub` 里，所有平台一套规矩。
新平台写一个适配器，加进 `im/runner.py` 的 `ADAPTERS`，再在 `im/qt.py` 的 `_Section.FIELDS` 里写上要填的字段。
